# Roadmap

Help decide what comes next in [Discussions](https://github.com/vumox/layout-forge/discussions) and the pinned [What should we build next?](https://github.com/vumox/layout-forge/issues/15) issue. Explain the task you want to finish, the output you need and what you currently use. Reactions help identify demand; they do not promise a delivery date.

## Shipped in 1.2.0

- [x] Copy link with compressed, versioned settings for the active tool.
- [x] Ctrl+K / ⌘K command palette across all 36 tools.
- [x] Installable PWA with offline access after the first online download.
- [x] Six tool GIFs and a repeatable recording script.
- [x] Static guides for mesh gradient, clip-path, glassmorphism and CSS Grid, with sitemap, robots and JSON-LD.
- [x] README comparison and dynamic stars/version badges.
- [x] Playwright smoke tests in CI; GitHub Pages deployment waits for successful CI.

## Explore with the community

- [ ] Localization: [#10](https://github.com/vumox/layout-forge/issues/10). Which languages should come first?
- [ ] More export formats and reusable presets based on real project workflows.
- [ ] Better media portability for shared designs without introducing a required account or server.
- [ ] New generators chosen from concrete community examples.

## Scope

Keep the core free, MIT licensed and usable without an account. Prefer changes that improve a real design or front-end task. This roadmap records priorities, not a release schedule.
