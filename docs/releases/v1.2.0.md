Layout Forge 1.2.0 makes results shareable, tools easier to find and the app available offline.

## Share, search and install

- **Copy link** restores the active tool's settings in another browser, including layout trees, palettes, seeds and mockup composition. Settings are compressed into the URL fragment.
- **Ctrl+K / ⌘K** searches all 36 tools, with arrow-key navigation, Enter to open and Esc to close.
- **Installable PWA** precaches tools, fonts and pages after the first complete online load. Updates prompt you to reload when ready.

## Guides and community

- Static guides for mesh gradients, clip-path, glassmorphism and CSS Grid, with canonical metadata, JSON-LD, sitemap and robots output.
- Six recorded tool GIFs, repeatable recording/icon scripts, dynamic README badges and the Why Layout Forge comparison.
- [Roadmap](https://github.com/vumox/layout-forge/blob/v1.2.0/ROADMAP.md), pinned [What should we build next?](https://github.com/vumox/layout-forge/issues/15) issue and three starter Discussions.

## Reliability and performance

- Narrowed Three.js runtime exports reduce the production 3D preview chunk from about 773 kB to 588 kB: [#12](https://github.com/vumox/layout-forge/pull/12).
- Layout-engine regression tests: [#13](https://github.com/vumox/layout-forge/pull/13).
- Mockup undo/redo controls use state, removing five React purity/ref warnings: [#14](https://github.com/vumox/layout-forge/pull/14).
- Fixed mockup Copy link and added browser checks for its history and PNG export, plus PNG snapshots from all ten 3D presets.
- CI runs **48 unit tests and 17 E2E scenarios**. GitHub Pages deploys after successful CI.
- Updated GitHub Actions and Node.js typings. TypeScript 7 remains deferred because its PR fails type checking; see the [PR decisions](https://github.com/vumox/layout-forge/blob/v1.2.0/docs/PR_REVIEW.md).

Thanks to [jnohclee-rgb](https://github.com/jnohclee-rgb) for the three focused contributions.

## Try it

[Open Layout Forge](https://vumox.github.io/layout-forge/), or download the static site archive below. The archive targets the `/layout-forge/` URL path used by GitHub Pages. For a different path, build from source with the appropriate `BASE_PATH`.

Shared links include settings, not uploaded images or videos. Remote media requires a connection. The project-path robots.txt is provided, but an authoritative robots policy needs control of the domain root. Nine existing lint warnings and the remaining 3D size warning are tracked separately.
