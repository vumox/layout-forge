We are collecting practical use cases for the next round of improvements.

Which of these would save you the most time?

1. **Accessibility:** keyboard editing and clearer screen-reader support for canvas tools.
2. **Localization:** tell us the language you would use and whether you can help review translations.
3. **Exports and presets:** describe the format or reusable setup you need in a real project.
4. **New generators:** include a reference and the output you would expect.

Reply with your choice and a short example of the task. If something else would help more, describe it.
