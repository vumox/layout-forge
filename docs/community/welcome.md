Welcome to Layout Forge Discussions!

Layout Forge brings 36 visual design and front-end tools into one browser workspace: CSS Grid and Flexbox, palettes, mesh gradients, shapes, glass effects, SVG backgrounds, motion and media tools.

Start with the [live app](https://vumox.github.io/layout-forge/). Use **Ctrl+K / ⌘K** to find a tool and **Copy link** to share its current settings. The app can be installed and used offline after its initial online download. Shared links include settings; uploaded images and videos must be supplied separately.

Use these categories:

- **Ideas:** describe a real workflow or propose a generator.
- **Show and tell:** show what you made, ideally with a shared link or screenshot.
- **Q&A:** ask how to get an effect or export into your project.
- **General:** talk about the project, documentation and contributing.

Browse the [roadmap](https://github.com/vumox/layout-forge/blob/main/ROADMAP.md) and [contributing guide](https://github.com/vumox/layout-forge/blob/main/CONTRIBUTING.md). If you find a bug, open an issue with the browser, steps and expected result.
